# ADR 0001 - Record Architecture Decisions

**Status:** Accepted
**Date:** 2026-09-02

## Context

MyWallet is a solo portfolio project meant to demonstrate senior-level architectural
thinking, not just working code. Decisions and their rationale need to survive as
documentation a reviewer can read without archaeology through commit history.

## Decision

Every structurally significant decision gets a short ADR in `docs/architecture/adr/`,
numbered sequentially, using this format: Context / Decision / Consequences.

## Consequences

- Slightly more upfront writing per decision.
- Reviewers (and future-you) can see *why*, not just *what*.
